This repository contains private, internal company work. It is not public, not open-source, and not free to reuse.

Before you continue, understand this clearly:

You are not allowed to share any part of this work with anyone outside the company.

That includes:

- Code (full or partial)
- Designs (Figma, screenshots, exports)
- Documentation

- Conversations about how the system works

Do not share with:

- Friends or classmates
- Other developers
- Online communities (Discord, Reddit, Stack Overflow, etc.)

- Anyone not explicitly approved

Even "just showing someone" or "asking for help" counts as sharing.

You may not take anything from this repo and use it in:

- Personal projects

## This is for internal work only

Everything in this repository is for working on this product only.

You are being given access so you can contribute, not so you can:

- Learn and reuse it elsewhere
- Share it
- Repurpose it

## Don't assume something is okay, ask first

If you're unsure about anything, ask before doing it.

Examples:

- "Can I show this to a friend?" -> No
- "Can I post this UI?" -> No (unless approved)
- "Can I reuse this pattern in another project?" -> No

When in doubt, assume the answer is no.
